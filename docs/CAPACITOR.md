# Capacitor (removed)

Inertia no longer ships a Capacitor Android shell. Phone installs use the **Tauri** project under [`apps/desktop`](../apps/desktop) (same shell as desktop), with on-device `inertia-api` via `jniLibs` (`libinertia_api.so`).

See [TAURI.md](./TAURI.md) for desktop and Android commands, lifecycle, and release assets.
